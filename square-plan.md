## 2. CONTRACT SHEET

> ⚠ **Signatures are generated code, verbatim.** Each operation that takes input takes ONE request record as its first parameter. Build it with an object initializer that uses the record's own property names, never flat arguments. `ListLocations` takes no record. Every signature ends `…, Square.Core.RequestOptions? requestOptions = null, System.Threading.CancellationToken cancellationToken = default)`, written below as `…`.
> ⚠ **Every SDK type is written fully qualified**, with the namespace its own source path implies (taken from the path the map gives for THAT type): `src/Square/Models/X.cs` is `Square.Models.X`, `src/Square/Models/Enums/X.cs` is `Square.Models.Enums.X`, `src/Square/Requests/<Ctl>/X.cs` is `Square.Requests.<Ctl>.X`, and `src/Square/Core/...` follows its own `namespace` line (cited per row).

Defaults that hold for all 23 rows (`sdk-map.md`, defaults table): **throw-only**. **Case B**: `Square.Core.Exceptions.ApiException<Square.Core.ErrorResponse.RawError>`, whose accessors are `StatusCode: HttpStatusCode`, `ReadAsBytes()`, `ReadAsString()` and `ReadAsJson<T>()`. **No pagination**. **Server group `Default`**. **Auth `options.BearerAuth`**. Every response envelope also carries `Errors (errors): IReadOnlyList<Square.Models.Error>?`, which the plugin reads through `SquareResponse.ThrowIfErrors`.
